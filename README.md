# 言必行，研必行

面向 211 计算机科班、准备 11408、目标 985 的个人择校工作台。

## 页面

- 院校池：按学校、独立招生单位、专业和方向浏览资料，并查看对应官方来源。
- 冲稳保：按科目、名额、分数、复试、方向、地域和个人偏好评分，支持四项目对比。
- 备考计划：保留空窗口，等待后续周计划文档接入。

## 数据口径

- 当前载入 33 所学校，数据文件位于 `../research/`。
- 严格 11408 由 `201 英语一 + 301 数学一 + 408` 自动判定。
- 缺失字段保留“待核验”，不把全校或学院总计划强行分摊为专业统考名额。
- 网站中的评分用于筛选顺序，不是录取概率或录取承诺。

## 本地运行

```powershell
npm.cmd install
npm.cmd run dev
```

构建与检查：

```powershell
npm.cmd run build
npm.cmd run lint
```

审计批次更新后，可在项目根目录运行：

```powershell
node tools\merge_audit_results.mjs
```
